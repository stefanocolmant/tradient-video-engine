Tradient Video Engine

Give it a topic. It researches, writes the script, records the voice, builds every scene from the words, adds sound, renders a vertical video and checks it, in the style you pick.

Open this folder in Claude Code (or Codex) and ask: "How do I run it?"

Set up (once)

  1. Install Node.js 20 or newer.
  2. In this folder run npm run setup (2-5 minutes: packages, render browser, free voice).
  3. Open the folder in Claude Code or Codex and ask "How do I run it?". Then just say what video you want.

Optional: an ElevenLabs or OpenAI key in .env for premium voices. Details in docs/SETUP.md.

How every video is made

Brief→Facts with sources→Script check→Voice + word timings→Storyboard check→Stills review→Render + sound→QA on the real file

Outlined steps are gates: nothing moves on until they pass. Rules: script, storyboard, scenes, quality checks.

Or run it yourself

npm run new -- my-video --style houseStart a video folder (brief, facts, script, storyboard).
npm run make -- my-videoScript check, voice, storyboard check, stills, render, QA.
npm run style:new -- acme --bg "#0E1116" --accent "#FF6B00" --mood energeticYour own style (option 2).
npm run style:learn -- my-lookTrain a style from styles/_inbox/my-look/ (option 3).
npm run style:test -- my-lookSample frames next to the references, with a match score.
npm run styles · npm run doctorList styles · check what's installed.
