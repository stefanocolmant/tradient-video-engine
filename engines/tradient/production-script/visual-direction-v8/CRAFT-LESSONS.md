# V8 construction lessons — candidate only

- Reusing a scene's look is insufficient when an arbitrary scene boundary replaces every object. Own the saved UI and its dimensional explanation in one scene family; export named source handles without changing legacy rendering.
- A screen field is a texture rectangle, not an independent mesh. Map its source pixels to the actual screen dimensions and world origin, crop the real saved values, and carry those into the corresponding geometry origins. The OHLC chart must retain its data and last-candle extension.
- Extending the lifetime of an environment can accidentally reactivate a different state branch. The first proof showed the retreating desk turning back into SUBMITTED after the original earlier-window ended. Freeze that departing source at the saved-rule frame while the configuration continues on its own clock.
- Rejected R1: source values overlapped; quantity units were tiny at the spoken anchor. Rejected R2: oversized quantity framing cropped two units; inactive parameter panels distracted during close views. R3 separates trajectories, settles panels before the close explanations, and frames all three units.
- Geometry should arrive at its readable endpoint on the word it explains. The start→anchor interval drives condition/size/limit reveals; the rest of each event can hold or stage the next viewpoint. This is separate from narration timing, which stays unchanged.
- Keep the original V7 composition, movies and assets preserved. No A23 parity or general original-film quality guarantee follows from a technical pass.
