# V6: transfer the construction technique, then inspect its new meaning

A23 remains the target. V4 is rejected; V5 was insufficient and the user explicitly requested continued comparison/improvement. V6 is a new candidate, not a declared aesthetic match. This package preserves Brian's recording, wording and duration, and all earlier exports. The old scheduled loop remains paused.

## Actual corrections learned in the proofs

- More repeated geometry did not fix V5. Its important forms remained uniformly sharp and stationary. Separate the context from the real sharp hero, reduce context contrast and move the camera with the object that explains the phrase. A table of hundreds of boxes is not itself a quality result.
- A23's `inspectionLens` is useful only if it inspects the actual feature. R2 pointed at empty chart pixels. V6 computes the last point's world position, puts the lens on its camera ray and uses the same underlying texture for the optical magnification. Point, label and qualifying state are separate: the drawing can interpolate without inventing intermediate market records.
- A word's anchor and an animation's end are different. The old condition flag became true only after the spoken “passes.” V6 changes the qualifying record at the anchor and lets the graphic settle afterward. The subsequent order lifecycle still waits for the completed checks and instruction.
- A fragmented surface must land on its transformed surface, not a guessed unrotated plane. All 144 destination tile corners are in the sample's world transform, and validation rejects a full-face swap before the last staggered tile has arrived.
- Parent the finished instruction's fields to its chassis. R1 moving proof showed the independently positioned rows slicing into the rotated document at the end. Final child transforms preserve the complete document through departure.
- Preserve visual source identity during transitions. Configured quantity cubes converge into the instruction; the sample folds edge-on into condition evidence; two actual filled bodies widen and flatten into two execution rows. A new message must not simply appear while the values it represents vanish.
- Camera, object and context share a world. The report travels beside the stationary price ladder; it does not force the book to shrink or move away to hide a collision. Its camera uses the same event easing. Keep the actual report eye distance bounded and test the receiving monitor at receipt.
- Distant prices must not compete with the eligible quantity. Far rows use a shared muted numbered texture, depth processing and lower light/label contrast. Only higher-price context updates independently, leaving the exact eligible example conserved.
- Check labels against the full movement envelope, including captions. A status label that clears captions at the opening can intersect them during an orbit. V6 engraves order identity on its base and places compact fill status above the caption region.
- A wide chart can become dead space. Use a close view of the relevant latest candles and threshold, then pull to the three stored units and limit. Do not hold the entire chart just because every data point exists.
- Review actual material response. The desk now has separate walnut, aluminium, glass, lamp reflector and screen spill. A single blue roughness/material treatment erased object identity. Keep glass reflections translucent enough to read the current action.

## Authoring contract

The canonical JSON supplies exact event timing, camera knots, inspection phases, source-record frames, return flight, values, captions and sound cues. `describe.mjs` reads authored directions/recipes from it; it does not overwrite them with a separate hardcoded prose template. It adds resolved camera/state/audio records for all 82 seconds. `check.mjs` verifies causality, quantity conservation, strict missing-input failures, cue mutation, tile completion and reverse state evaluation. These checks cannot grade art direction.

Source dimensions/material algorithms still live in the components and are explicitly identified in the recipes. New visuals require their own geometry, source-to-destination correspondence, camera progression and moving proofs. No claim of arbitrary-scene generation or automatic quality is made.
