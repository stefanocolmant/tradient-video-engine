# Tradient Video Engine

@AGENTS.md

## Claude Code shortcuts

These slash commands run the same workflows as AGENTS.md:

- `/setup` checks and installs everything, then shows the three style choices.
- `/make-video <topic>` makes a video from a topic (or a script you paste).
- `/new-style` builds your own style from brand colours, fonts, logo and a mood.
- `/train-style <name>` learns a style from pictures, videos and websites.

You can view images: always LOOK at the stills sheet, the QA review sheet and style cards before
saying a step is done.
